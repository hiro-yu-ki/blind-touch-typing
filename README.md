# 仕事打（SHIGOTO TYPE）

実務に近い日本語の長文で、IME入力とブラインドタッチを練習するローカルWebアプリです。メール、議事録、社内報告、提案書に加え、1,500〜1,800文字級のAI・開発プロンプトを含む15本のオリジナル課題を収録しています。主要機能は外部APIやアカウントなしで動きます。

## このアプリ独自の練習設計

- **精度優先コーチ**: 300文字/分のような一律目標ではなく、本人の直近記録から最大10%だけ高い次の目標を提示します。正確率95%未満では速度を上げません。
- **最初のズレ診断**: 誤字が生じた文字位置、見本、実際の入力を並べて表示します。一文字の挿入・欠落による連続したズレを、何十件もの誤打として重複計上しません。
- **長文チェックポイント**: 1,000文字を超える課題を約250文字ずつの区間として表示し、現在位置へ自動追従します。
- **プロンプト構造ナビ**: `【役割】`、`【目的】`、`【必須要件】`、`【評価】` などの構造を画面上で可視化し、今どの要素を書いているか把握できます。
- **習熟ルート**: 基礎、正確性、実務、AI・開発の順で、現在の段階をホーム画面に表示します。

## 動作環境

- Windows 10 / 11
- Node.js 20以上（確認環境: Node.js 24）
- 最新版の Chrome または Edge を推奨

## インストールと起動

普段は **`仕事打を起動.bat` をダブルクリックするだけ**で起動できます。`start.bat` から起動しても同じです。初回のみ必要なパッケージを自動インストールし、起動完了を待ってブラウザーを開きます。すでに起動している場合は、サーバーを重複起動せずブラウザーだけを開きます。

デスクトップから起動する場合は、デスクトップに配置した `仕事打を起動.bat` を使います。これは本体をコピーせず、`%USERPROFILE%\product\ブラインドタッチ` にある正規ランチャーを呼び出します。本体側の `start.bat` だけをデスクトップへ移動すると、`launch.ps1` や `package.json` を見つけられないため起動できません。

起動に失敗した場合、ウィンドウがすぐ消えずエラー内容を表示します。詳しい診断情報は `logs/launcher.log`、サーバー側の情報は `logs/server-error.log` と `logs/server-output.log` に保存されます。履歴や課題データは変更しません。

手動で起動する場合は、PowerShellでこのフォルダーを開き、次を実行します。

```powershell
npm install
npm run dev
```

表示された `http://127.0.0.1:5173` をブラウザーで開いてください。配布用ビルドは `npm run build`、ビルド確認は `npm run preview` です。ランチャーから起動したサーバーは非表示で動作します。終了するときは、デスクトップの `仕事打を終了.bat` をダブルクリックしてください。記録済みPIDと起動コマンドを照合し、このアプリのNode.jsプロセスだけを停止します。

## 基本操作

1. ホームの「時間制限なしで始める」、または「課題を選ぶ」を押します。
2. 入力方式を「実務入力」または「ローマ字」から選びます。
3. 「練習」は時間無制限、「チャレンジ」は90秒です。
4. 練習中は `Esc` で一時停止・再開できます。画面上部から音、停止、やり直しを操作できます。
5. 完了後は結果を確認し、同じ課題へ再挑戦できます。

すべての主要なボタン、選択欄、入力欄は `Tab` / `Shift + Tab` と `Enter` / `Space` で操作できます。

## 入力方式の仕様と制約

### 実務入力（主モード）

- 日本語IMEをオンにし、表示文面をそのまま入力します。
- `compositionstart` から `compositionend` までの未確定文字列は進捗・誤字判定を待ち、確定後の文字列で比較します。
- Backspace、Delete、選択置換、改行、全角句読点を通常の入力欄として扱います。誤って入力しても編集して先へ進めます。
- 貼り付けは編集手段として許可しますが、貼り付けた文字数を「実入力文字数」から除外し、物理打鍵にも加えません。
- IME内部の全物理打鍵や変換候補はブラウザーから完全には取得できません。実務入力では「次のキー」を推測せず、実際に検出できた `keydown` のみ可視化します。

### ローマ字練習（補助モード）

- 日本語IMEをオフにし、半角英字で入力します。
- 表示文と読みを別データで管理しています。`し` は `shi` / `si`、`ち` は `chi` / `ti`、`つ` は `tsu` / `tu` など、一般的な複数入力を許可します。
- 拗音、促音（子音の重ね打ちまたは `xtu` / `ltu`）、撥音、長音、句読点に対応します。
- 撥音の `n` は読みやすさを優先して `n` と `nn` の両方を許可します。日本語IME固有の後続文字による確定規則は再現していません。
- 長文全体ではなく、各文書から切り出した実務表現を練習します。

## 指標とゲームルール

- **実入力文字数**: 完了済みの日本語文字数（貼り付け分を除く）。ローマ字モードでは完了した読みの文字数。
- **物理打鍵数**: ブラウザーが取得できた文字キー、Enter、Backspace、Delete の `keydown` 回数。IMEやOSが隠す打鍵は含みません。
- **正確率**: `実入力文字数 ÷ (実入力文字数 + 修正操作 + 誤打) × 100`。小数第1位まで表示します。
- **文字/分**: `実入力文字数 ÷ 経過秒 × 60`。日本語文字数ベースです。
- **物理打鍵/分**: `取得できた物理打鍵数 ÷ 経過秒 × 60`。一般的な英語5打鍵換算WPMとは分けて表示します。
- **チャレンジ得点**: `(文字数×10 + 1秒あたり文字数×120 + 最大コンボ×2) × (正確率÷100)^3` を四捨五入。正確率を3乗で掛けるため、速いだけの乱打では高得点になりません。

## 保存場所

履歴（最大50件）と設定はブラウザーの `localStorage` に保存します。キーは `shigoto-type-history-v1` と `shigoto-type-settings-v1` です。サーバーへの送信はありません。履歴画面から削除できます。ブラウザーのサイトデータを消すと履歴も消えます。

## 課題の追加方法

`src/data.ts` の `lessons` に次の項目を追加します。

- `id`: 重複しない英数字ID
- `title`, `difficulty`, `genre`, `minutes`
- `text`: 実務入力で使う完成文（改行は `\n`）
- `romanExcerpt`: ローマ字練習で画面に見せる短い日本語
- `reading`: `romanExcerpt` のひらがな読み

未知の記号はその文字自体が入力候補になります。複数のローマ字表記を追加する場合は `src/typing.ts` の表を更新し、テストも追加してください。

`text` 内に `【役割】` のような全角かっこ付き見出しを書くと、練習画面の構造ナビへ自動表示されます。1,000文字以上の課題では長文チェックポイントも自動で有効になります。

## 初心者の目安

最初が1文字/分でも異常ではありません。ホームポジションと担当指をまだ覚えていない段階では、速度を測るより「キーボードを見ずに一文字を正しく押せたか」を優先します。

1. まず毎日5〜10分、時間制限なしで練習します。
2. 連続して正確率95%に届くまでは、速度を上げません。
3. 安定したら、現在の文字/分より10%だけ高い目安へ進みます。
4. 長文は一度に完走しようとせず、250文字のチェックポイント単位で練習します。

上達期間は練習頻度、過去の入力経験、手の使い方によって大きく異なるため、特定の日数で300文字/分に到達すると保証はできません。週単位で「正確率」「手元を見た回数」「前回より楽に打てたか」を確認してください。

## テスト

```powershell
npm test
npm run build
```

ローマ字の複数表記、促音・長音・句読点、指標計算を自動テストしています。手動確認では実務入力のIME確定、修正、貼り付け、一時停止、時間切れ、履歴保存、各画面の狭幅表示を重点的に確認します。

## キーボード表示の限界

画面表示は日本語JIS配列を基本にした学習用ガイドです。OS、接続キーボード、配列変更ソフトによって実際の印字や `KeyboardEvent.key` は異なります。物理位置を完全には識別できないため、利用者固有の配列を断定しません。
